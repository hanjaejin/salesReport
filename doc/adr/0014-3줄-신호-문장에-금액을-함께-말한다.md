# ADR-0014. 3줄 신호 문장에 금액을 함께 말한다

- 상태: 채택
- 일자: 2026-08-27
- 관련 마일스톤: M6 (배포 후 운영 피드백)
- 결정자: 사용자 지시 ("1인당 구매액이 %로 나오는데 금액으로 나오게 바꿔줘", 금액+변화 병기 선택)

## 배경

배포된 화면을 보고 소유자가 지적했다.

```
그저께와 비교하면, 손님 수(14.7%) 영향이 컸어요 — 1인당 구매액은 13.2%였어요
```

**"구매액은 13.2%였어요"는 비문이다.** 금액을 백분율로 서술하고 있다.
읽는 사람은 "1인당 구매액이 13.2원인가?" 로 잠깐 멈춘다. 30초 안에 읽히는
문장이어야 하는데, 멈추게 만드는 문장이었다.

이 문형은 명세 7.4가 **문자열 그대로 확정**한 것이다.

> 3줄(신호): "**그저께와 비교하면**, {주어}({값}%) 영향이 컸어요 — {보조어}는 {값}%였어요"

그리고 CLAUDE.md는 "브리핑 템플릿 문자열 임의 수정 금지 — 명세 7.4의 문자열·변형
목록이 전부다" 를 규정한다. 즉 **명세를 고치지 않고는 못 고치는 문장**이었다.

## 왜 명세가 이렇게 적었는가

3줄의 목적은 "어제와 그저께의 차이가 **무엇 때문인가**" 의 분해다.
손님이 늘어서인지, 한 사람이 더 많이 사서인지를 가른다.
분해를 하려면 두 항을 **같은 단위**로 놓아야 해서 양쪽을 % 로 맞춘 것이다.
설계 의도는 옳았고, 표기가 사람을 놓쳤다.

## 결정: 금액과 변화를 함께 말한다

```
그저께와 비교하면, 손님 수(929명, 14.7%) 영향이 컸어요
— 1인당 구매액은 3,229원으로 13.2% 늘었어요
```

두 질문에 한 문장으로 답한다 — **"얼마인가"** 와 **"얼마나 달라졌나"**.
원인 분해(% 비교)도 그대로 살아 있다.

### 함께 고친 것 — 부호와 겹말

`-4.1%` 를 그대로 두고 "줄었어요"를 붙이면 **"-4.1% 줄었어요"** 라는 겹말이 된다.
보조어 쪽 백분율은 **절댓값**으로 넣고 방향은 말로 알린다.

| 조건 | 문구 |
|---|---|
| `support_pct > 0` | 늘었어요 |
| `support_pct < 0` | 줄었어요 |
| `support_pct == 0` | 같았어요 |

주어 쪽은 부호를 유지한다 (`손님 수(73명, -21.5%)`) — 괄호 안은 값의 나열이지
서술이 아니라 겹말이 생기지 않고, 방향을 즉시 읽을 수 있다.

## 불변식 1을 지킨 방법

금액·단위·절댓값·방향 판정은 **전부 `pick_signal()`(계산 계층)에서 끝난다.**
문장 계층은 여전히 치환만 한다. 새 값은 이미 JSON에 있던 것을 옮겼을 뿐이다.

| 치환 필드 | 출처 |
|---|---|
| `subject_amt` / `support_amt` | `deal_cnt`·`avg_ticket` (계산 JSON 기존 필드) |
| `subject_unit` / `support_unit` | `SIGNAL_UNITS` 상수 |
| `support_pct_abs` | `pick_signal` 에서 `abs()` |
| `support_direction` | `pick_signal` 에서 부호 판정 |

**새로 계산한 숫자가 하나도 없다.** `test_briefing_lines_use_only_json_numbers`
(3줄 안의 모든 숫자가 JSON 값 집합에 존재)가 그대로 통과하는 것이 근거다.

조사도 문제없다 — "원"·"명" 둘 다 받침이 있어 뒤에 붙는 조사가 "으로"로 같다.
받침에 따라 갈리는 경우가 생기면 ADR-0007 결정 3처럼 계산 계층에서 골라야 한다.

## 결과

- 긍정: 비문이 사라졌고, 점포장이 알고 싶어 하던 **실제 금액**이 브리핑 3줄 안으로 들어왔다.
  이전에는 [자세히 보기]를 펼쳐야 볼 수 있었다.
- 긍정: 하락한 날의 문장이 자연스러워졌다 (`-4.1%였어요` → `4.1% 줄었어요`).
- 부정: **문장이 길어졌다.** 좁은 화면에서 세 줄로 접힌다.
  30초 약속에는 영향이 없다고 판단했지만, 길이가 문제가 되면 주어 쪽 금액
  (`손님 수(929명, 14.7%)` 의 `929명`)을 먼저 덜어내는 것이 좋다 — 주어는 이미
  "영향이 컸다"는 서술을 받고 있어 금액이 없어도 비문이 아니다.
- 부정: 명세 7.4의 확정 문자열이 하나 바뀌었다. 1·2줄과 변형 목록은 그대로다.
- 중립: 기존 브리핑 1,188건을 다시 만들어야 한다 (문장이 DB에 저장돼 있으므로).
  파생 시드가 결정적이라 숫자는 한 자리도 바뀌지 않는다 — 문장만 바뀐다.

## 명세와의 관계

- 명세 7.4의 3줄 템플릿 **1개**를 교체한다. 1줄·2줄·변형 목록·임계값은 전부 불변.
- 명세 7.4의 "단일 문형 유지"는 지킨다 — 변형을 늘리지 않았다.
- 명세 7.4의 표기 규칙(금액은 정수 원·천단위 콤마, % 는 소수 1자리)을 그대로 따른다.
- 명세 14장의 금지(새 숫자 계산·원인 단정·전문용어)는 그대로 적용된다.
